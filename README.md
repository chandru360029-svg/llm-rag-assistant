# Project 26 — Furniture Delivery Assistant

A beginner-friendly RAG capstone built with Python, Flask, LangChain, LangGraph, ChromaDB, sentence-transformers, and Groq.

## Features

- Ask questions grounded in the three furniture policy documents.
- Display the filenames returned by document retrieval.
- Estimate base, distance, carrying, and optional assembly charges using deterministic Python logic.
- Return `MANUAL_QUOTE_REQUIRED` with `total: None` for distances above 30 km.
- No delivery tracking, scheduling, refunds, replacements, or entrance-fit decisions.

## Windows setup

Open Command Prompt in this project folder and run:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
copy .env.example .env
```

Edit `.env` and replace `your_groq_api_key_here` with your own Groq API key. Do not share or commit the key.

## Ingest the documents

```bat
python ingest.py
```

The first run downloads the embedding model and may take a few minutes. Re-running ingestion rebuilds the local ChromaDB index instead of accumulating duplicate chunks.

## Start the application

```bat
python app.py
```

Open this address in your browser:

http://127.0.0.1:5000

Keep the terminal open while using the app.

## Demonstration questions

- Does assembly include wall drilling?
- How soon should delivery damage be reported?
- Where is my delivery vehicle? (The supplied documents do not provide tracking information.)

## Expected calculator examples

1. 15 km, 2 items, floor 3, no lift, assembly required: base ₹500 + distance ₹150 + carrying ₹600 + assembly ₹400 = **₹1,650**.
2. 8 km, 1 item, ground floor, lift available, no assembly: **₹500**.
3. 35 km: status `MANUAL_QUOTE_REQUIRED`, total `None`.

## Notes

- A delivery estimate is not a booking or approval.
- Assembly excludes wall drilling and electrical work.
- Damage must be reported within 48 hours with order reference, item description, and photographs.
- The LLM uses retrieved context for document questions; the delivery calculation is performed by Python.
